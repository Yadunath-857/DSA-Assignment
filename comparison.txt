ANALYSIS

For the given input, the load factor is 87.5%.

Linear probing produced a longer search sequence for the non-existing
ID 80.

Quadratic probing required fewer probes for the non-existing ID 80.

Double hashing also required fewer probes for the non-existing ID 80
and uses a different probe sequence.

The experiment shows that the choice of collision resolution technique
affects the number of probes and therefore affects hash table
performance.
